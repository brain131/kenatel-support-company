
# IT Support Portal

## About the Project
The IT Support Portal is a static website designed to help employees identify common IT problems and find troubleshooting solutions before contacting the IT support team.

## Features
Home page with a search bar and popular IT problems.
 Knowledge Hub for browsing IT problems and solutions.
 Hardware troubleshooting guides.
 Software troubleshooting guides.
 Network troubleshooting guides.
 Security troubleshooting guides.
 Contact page with IT support information and a contact form.
 Login page interface for employees.
A dashboard
